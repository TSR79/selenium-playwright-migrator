# Privacy Policy

**Project:** Selenium-to-Playwright Migrator  
**Version:** 0.1.0  
**Last updated:** November 15, 2026

## Overview

Selenium-to-Playwright Migrator is an instruction-driven Kiro Power designed to assist with migrating Selenium Java automation projects to Playwright TypeScript frameworks.

## Data Collection

The Power's current distribution does not include its own telemetry, analytics, external API integration, network client, or MCP server.

The project maintainer does not operate a separate backend service for this Power.

## Project Files and AI Processing

The Power instructs the Kiro agent to analyse source and target automation frameworks in the user's development environment.

Project files and prompts may be processed by Kiro according to its configuration, permissions, and applicable privacy policies. This project's Privacy Policy does not govern Kiro's own data processing.

## File Modifications

The Power instructs the agent to preview proposed changes and request explicit approval before modifying files. Users should also configure Kiro's native filesystem and command-execution permissions appropriately.

## Sensitive Information

Users should avoid submitting passwords, API keys, confidential client data, or proprietary code unless authorised under their organisation's policies.

## Third-Party Services

This Power does not bundle an external service integration. Users who install or operate it through Kiro are also subject to the relevant Kiro and AWS policies.

## Changes to This Policy

This policy may be updated if future releases introduce new capabilities or data-processing behaviour.
